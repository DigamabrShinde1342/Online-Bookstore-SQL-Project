# Online Bookstore SQL Project

## Objective
Analyze bookstore sales, customer behavior, revenue, and inventory using PostgreSQL.

## Tools Used
- PostgreSQL
- pgAdmin
- SQL

## Tables
1. Books
2. Customers
3. Orders

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- HAVING
- JOIN
- ORDER BY
- Aggregate Functions

## Basic Queries
- Fiction books
- Books after 1950
- Customers from Canada
- Total stock
- Most expensive book
- Total revenue

## Advanced Queries
- Total books sold by genre
- Most frequently ordered book
- Customer spending analysis
- Remaining stock analysis

## Project Insights
- Revenue analysis
- Inventory tracking
- Customer analysis
- Genre-based sales analysis
